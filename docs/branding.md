# Vidarr branding

The selected brand is Rune, proposal 5. The left V stroke and ARR letters are fuchsia
(`#FF008E`), the play triangle is blue (`#4F8CFF`), and the right stroke and VID letters
are cream (`#FFFFC5`).

The approved full wordmark preview is [the Rune logo](assets/vidarr-rune-logo.png).
The transparent application emblem is `apps/web/public/vidarr-rune-mark.png`.
The sidebar renders that emblem beside accessible text, with the same wordmark colors.
A distinct asset filename avoids reusing the previous logo's cached URL. The previous PNG
remains available for existing references.
