# Bundled Kabel font

File: `kabel.ttf`; internal family: Kabel; style: Book; PostScript name: KabelBook.
Downloaded 2026-11-04 from https://font.download/dl/font/kabel.zip.
Source information: https://font.download/font/kabel.

The font's embedded copyright/name record identifies A. Carr and states “Freeware!”
The original font bytes and name records are retained. This is the freeware Kabel Book
digitization, rendered with the overlay's bold style; it is not the commercial Kabel Black face.

The DLL embeds the font as a resource. Generated ASS tracks include its font data so server
burn-in can use it without installing system fonts. No font is downloaded at runtime.
