# Implementation traceability checklist

Create a working matrix:

| Requirement | Existing behavior | Planned code paths | Tests/evidence | Status |
|---|---|---|---|---|

Check domain states, migration compatibility, indexes, API authorization/validation/idempotence,
partial failure, UI loading/error/accessibility, provider reconciliation, scale/query count,
credential boundaries, tests, builds, documentation, changelog, and deployment evidence.

Before completion, mark every acceptance criterion complete, deferred with user agreement, or
blocked with concrete evidence.
